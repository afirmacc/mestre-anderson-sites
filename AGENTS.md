# Trabalho neste repositório

Este repositório é a fonte da skill Mestre Anderson para Codex e do plugin para Claude Code. Leia [`MAINTENANCE.md`](MAINTENANCE.md) antes de mudar instruções, scripts ou documentação.

- Preserve compatibilidade com os dois agentes e escreva em português do Brasil.
- Registre cada melhoria coerente em um commit próprio, depois de validar o que mudou. Atualize a versão do plugin e crie uma tag para cada versão publicada.
- Use o autor humano real no commit e registre no corpo quais ferramentas implementaram e revisaram a mudança, conforme `MAINTENANCE.md`.
- Preserve o histórico: para desfazer uma regressão em `main`, prefira `git revert` e um novo commit. Não reescreva o histórico compartilhado sem pedido explícito.
- Publique no remoto da Afirma somente quando a conversa autorizar manutenção e publicação. Para cópias de terceiros, prepare uma contribuição por pull request.
- Não inclua credenciais, dados pessoais nem detalhes internos de projetos nos exemplos públicos.
