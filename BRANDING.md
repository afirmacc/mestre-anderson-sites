# Avatar da Afirma no GitHub

Em 13 de novembro de 2026, o avatar da organização [`afirmacc`](https://github.com/afirmacc) foi trocado do identicon padrão rosado pelo [símbolo azul da Afirma](assets/afirma-avatar.png), fornecido em `https://afirma.cc/apple-touch-icon.png`.

O avatar é uma **configuração da organização**, então aparece em outros repositórios da Afirma. A configuração em si não faz parte do Git; este arquivo e as imagens guardam qual arte foi aplicada e quando. Para reaplicar, acesse as configurações gerais da organização no GitHub e envie `assets/afirma-avatar.png` como foto de perfil. Para voltar ao visual anterior, envie [`assets/afirmacc-avatar-anterior.png`](assets/afirmacc-avatar-anterior.png). A troca de avatar não altera o histórico Git dos demais repositórios.
